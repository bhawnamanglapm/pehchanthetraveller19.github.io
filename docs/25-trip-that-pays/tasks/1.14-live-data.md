## Why it matters

These facts change and come from free sources, each with terms that must be kept.

## Sources

| Data | Source | Rules |
|---|---|---|
| **Travel advisory** | GOV.UK content API: `/api/content/foreign-travel-advice/<country>` | Its licence needs a credit, so the page shows "UK government travel advice" with a link. India's foreign ministry has no API |
| **Country basics** | REST Countries: currency, languages | Free. Cached for a week |
| **Exchange rate to ₹** | **Frankfurter** for THB, MYR and USD | Cached 24 hours. Shown as "Rate from [date]" |
| **Dirham (AED)** | Fixed rate to the US dollar, **3.6725**, times Frankfurter's USD→INR | Frankfurter doesn't carry AED. Admin confirms the peg on the central bank's site monthly (1.38) |
| **Nepali rupee (NPR)** | Fixed rate to the Indian rupee, **1.6** | Frankfurter doesn't carry NPR. Admin confirms monthly |
| **Dong (VND)** | `destination` dong rate, entered monthly by admin with a source | Frankfurter doesn't carry VND |
| **India** | No advisory or exchange rate shown; country basics only | |

## Not used, and why (so no one adds them later by mistake)

| Service | Why not |
|---|---|
| Open-Meteo | Its free API is non-commercial only, and this page earns money. Climate is entered by admin. A live forecast needs a licence check first (3.01) |
| Calendarific | Free plan is 500 calls a month with a credit; paid starts at $12 a month. Festivals are entered by hand |
| Nominatim on the page | 1 request a second, caching required, no search-as-you-type. Admin looks up stays once |
| OpenStreetMap tiles | Their own usage rules; check before embedding any map (3.01) |

## Acceptance criteria

- [ ] Each destination shows its advisory with the credit, currency, languages and ₹ rate with its date.
- [ ] AED and NPR rates are computed from the fixed values; VND reads from Strapi.
- [ ] If a source fails, the last cached value shows with its date; if there's none, the fact says "unavailable" rather
      than showing a wrong number.
