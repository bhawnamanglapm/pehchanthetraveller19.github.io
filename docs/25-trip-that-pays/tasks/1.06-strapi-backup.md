## Why it matters

Strapi runs on one EC2 server with SQLite and will hold every checked fact and stay for both apps. One disk failure
without a backup loses months of checking.

## What to do

1. Find out what backs up the SQLite file today, if anything, and write it down.
2. If nothing does: a daily job on the server copies the database file (and Strapi's uploads folder, which holds the
   stays' written-OK files) somewhere off the server. Use a safe copy method so a write in progress doesn't corrupt
   the copy.
3. Keep at least 30 daily copies.
4. Email admin if a backup fails.
5. **Ask the owner before anything that costs money** (for example paid storage).
6. Restore a copy to a test machine once, and write the restore steps down.

## Acceptance criteria

- [ ] Written note of what existed before.
- [ ] Daily off-server backups running, with failure emails.
- [ ] One successful test restore, with the steps written in the admin runbook (1.38).
