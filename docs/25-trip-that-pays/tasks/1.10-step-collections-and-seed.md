## Why it matters

The stage 1 cards are built once in code (1.26) and filled from these two collections. Admin changes advice, links,
required/optional and the rule numbers without a code release. E3 appears later the same way.

## Collections and fields

| Collection | Fields |
|---|---|
| **step-guide** | step ID (E1, E2, E3, P1–P4, S1–S3), "how to do it" text, required or optional, rule numbers (pitch target, default 5; red threshold, default 14 days), shown (yes/no), `checkedOn` |
| **step-link** | step ID, label, URL, destination (optional), kind (official, affiliate network, platform), allowed domains, minimum followers, commission note with source, note on conflicting sources, broken (set by the weekly check), shown (yes/no), `checkedOn` |
