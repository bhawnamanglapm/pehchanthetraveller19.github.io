## Why it matters

The trip page is its own product, so it must be able to ship without breaking the rest of the site.

**Changed 15 Nov 2026 (owner, D2):** the trip pages are part of the existing Next.js app at
`www.pehchanthetraveller.com/trip/`, not a separate app. They were first built in their own private repo, then merged
in behind a `tripApp` switch that stays off until launch (1.40). While it's off, every `/trip/` page and `/api/trip/`
route answers 404. So work on them can't break the live site. The table below is the original plan for a separate
app, kept for the record; the acceptance criteria are for the merged setup.

## What was planned (separate app, replaced)

| Item | Detail |
|---|---|
| **Repo** | A new **private** Git repo (name proposed: `pehchan-trip`). The main website repo is public, so nothing for this app goes there except the nav link (1.20) |
| **Stack** | Next.js 16 (App Router), Tailwind 4, daisyUI 5, TypeScript, matching the existing app so code can be copied across (1.04) |
| **Hosting** | A new Vercel project, linked to the repo. Production on the `main` branch; a preview per pull request |

| **Environment variables** | `STRAPI_URL`, `STRAPI_READ_TOKEN`, `STRAPI_WRITE_TOKEN` (limited to `offer-report` and `stay-suggestion` create), `REVALIDATE_SECRET`, `CRON_SECRET`, `RESEND_API_KEY`, `ADMIN_EMAIL`, analytics key (1.19). Phase 3 adds `ANTHROPIC_API_KEY`, `RAZORPAY_*`, database URL. **Values live in Vercel only, never in the repo** |
| **Routes** | `/` landing · `/start` first visit · `/trip/0a` · `/trip/0b` · `/trip/1` · `/trip/1/ready` (checkpoint) · `/trip/2` · `/trip/3` · `/example` worked example · `/legal/privacy` · `/legal/terms` · `/legal/affiliate-disclosure` · `/api/*`. Phase 2 adds `/hi/...` |
| **Quality gates** | Lint, type-check and unit tests run on every pull request. A pull request can't merge if they fail |
| **Repo README** | How to run locally, where each env var comes from (not its value), and links back to this plan |

## Rules

- Small commits with descriptive messages.
- No paid dependency is added without the owner's yes.
- Secrets are never committed; add a secret-scanning check if the Git host offers one free.

## Acceptance criteria

- [ ] The `/trip/` pages and `/api/trip/` routes are in the main app, behind the `tripApp` switch, and answer 404
      while it's off.
- [ ] The trip env vars exist in the main Vercel project with values (`STRAPI_TRIP_READ_TOKEN`,
      `STRAPI_TRIP_WRITE_TOKEN`, `REVALIDATE_SECRET`, `CRON_SECRET`, `RESEND_API_KEY`, the analytics id), and none
      appear in a repo.
- [ ] Lint, type-check and tests run on pull requests and block merging when they fail.
- [ ] Every route in the list exists with a title.
