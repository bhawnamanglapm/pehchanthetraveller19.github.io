## Why it matters

Tours earn commission (GetYourGuide about 8%, Klook 5–6.5%) and give the film its scenes.

## What to build

- Server routes for the GetYourGuide Partner API, Klook and Viator Partner API (whichever 2.01 confirms access to),
  keys in environment variables.
- 0b: a "Tours near your base" list per destination.
- Stage 2: tours for today's area in the Today view.
- Each tour: name, price with time shown (if allowed), labelled affiliate link opening in a new tab.
- Caching and price display within each programme's rules (2.01).
- `affiliate_click` with partner and stage.

## Acceptance criteria

- [ ] Every tour link is labelled and tracked.
- [ ] A partner API failure hides that partner's list without breaking the page.
- [ ] Display rules match the written notes from 2.01.
