## P1 · Join loyalty programmes before booking (required)

| | |
|---|---|
| **Fields** | Rows: programme name, airline or hotel, date joined, last 4 digits of membership number (optional, **4 digits only**), date of first booking |
| **Warns** | If the first booking date is before the join date: "Booked before joining. Check whether you can claim these points." |
| **Done** | At least one airline and one hotel programme, each joined on or before its first booking |
| **Links** | Air India Maharaja Club, IndiGo BluChip, and the destination's corridor airlines and chains (1.36). Outbound only, no loyalty API |
| **Feeds** | P2's lists |

## P2 · One main programme of each kind (required)

| | |
|---|---|
| **Fields** | Main airline, main hotel chain (both chosen from P1 rows), why, rule on how long points last with a source link (required) |
| **Done** | Both chosen, each with a sourced expiry rule |
| **Feeds** | Stage 2 "log this flight" reminder, stage 3 tips on using points |

## P3 · How you'll pay abroad (required abroad)

| | |
|---|---|
| **Fields** | Rows: method name, markup %, ATM fee, reload fee, what happens to leftover money, source link. **No card-number field** |
| **Auto** | "Not needed" when the 0a destination has `inIndia = yes` |
| **Checks** | Percentages and fees are numbers |
| **Done** | At least one method with markup % and a source link |
| **Links** | None, on purpose: Pehchan recommends no card |
| **Feeds** | The money diary's default payment method |

## P4 · Travel card sign-up bonus (optional)

| | |
|---|---|
| **Fields** | Card name, bonus terms, spend needed, deadline, annual fee, source link |
| **Shows** | "Reachable" or "not reachable": spend needed compared with the 0a trip budget |
| **Done** | A decision (applying or not) and a source link, or skipped |

## Acceptance criteria

- [ ] P1 warns on a booking before joining, and the membership field refuses a 5th digit.
- [ ] P3 is Not needed for an India destination and counts as done for the checkpoint.
- [ ] P4 shows reachable or not against the budget.
