## Why it matters

It picks the launch destination and tests whether the eight questions and the scoring actually help. If they don't,
the page design changes before code is written.

## What to do

1. PM makes a Google Sheet (or Notion table) with one row per place and one column per question:

   | # | Question | Where the answer comes from in phase 0 |
   |---|---|---|
   | 1 | Is there a story only I can tell? | Owner |
   | 2 | Do Indians want to go there? | Owner checks Instagram and YouTube by hand |
   | 3 | How crowded is it with creators? | Owner counts recent YouTube videos by hand |
   | 4 | Can my audience afford it? | Flight search plus a daily cost range, with sources |
   | 5 | How easy is the visa? | The official government site, dated |
   | 6 | Can it earn? | Bookable stays, tourism board, creator-friendly stays |
   | 7 | Can I film there? | Official filming and drone rules, plus how safe filming alone feels |
   | 8 | Is the timing right? | Official festival calendar and climate months |

2. Score each 0–3. Add a bonus point for places already visited.
3. Write down the weight used for each question (start with all equal) and note any you'd change.
4. Every fact gets a source link and the date checked.
5. Pick one place and write the one-line "why".

## What to record for the build

- How long each question took to answer, and which were hard to source.
- Any question that didn't change the decision (a candidate for a lower weight).
- The final weights, which become the starting values in `trip-page-settings` (task 1.11).

## Acceptance criteria

- [ ] 3–5 places scored, every fact with a source and a date.
- [ ] One place picked and the "why" line written.
- [ ] Notes on time taken and starting weights handed to the PM.
