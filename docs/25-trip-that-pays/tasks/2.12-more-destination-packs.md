## Why it matters

Each new destination widens who the page serves and adds booking commission. The pace is set by how fast admin can
check facts and stays, never faster: about one destination a month is the plan, adjusted by the first pack's timing.

## Target

About one new destination a month, anywhere in the world, with no fixed list (README §1). **Changed 16 Nov 2026
(owner):** the target used to be India plus the five corridor destinations (Dubai/UAE, Vietnam, Thailand, Malaysia,
Nepal). Rates: most currencies come from Frankfurter. Vietnam needs the monthly dong rate, and Dubai/UAE and Nepal
use fixed rates. A currency none of these covers needs a code change first (1.14).

## How

- Order destinations by what travellers pick in 0a (from analytics), plus AI shortlists made the same way as 1.41.
- Same ten items and stay check as 1.36, with Hindi versions (2.06).
- Each destination appears only when every item is published, sourced and dated.
- Note each pack's time to keep the monthly pace honest.

- [ ] The time per pack is written down.
