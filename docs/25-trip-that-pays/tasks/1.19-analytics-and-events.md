## Why it matters

The main measure (trips reaching stage 3 with a Trip Balance), drop-off, commission per trip and the most-skipped
steps all come from these events. They must carry no personal data.

## The tool

Decided in D7. First check what the existing Next.js app and the main website use: the main site's
`assets/js/analytics.js` supports GA4 and Plausible through `data-track` attributes, and neither is configured yet.
Using the same tool on both sites lets one funnel run from the nav click to `trip_started`. **Nothing paid without the
owner's yes.**

## Events

| Event | Properties | Fires when |
|---|---|---|
| `trip_started` | mode | First-visit screens done |
| `mode` | Creator or Just plan it safely | Mode chosen or switched |
| `stage_completed` | stage (0a, 0b, 1, 2, 3) | A stage's done rule passes |
| `step_completed` | step ID | A step's rule passes |
| `step_skipped` | step ID, type of reason (from a short list, never free text) | Skip with reason |
| `checkpoint_status` | green, amber or red | On the departure date |
| `affiliate_click` | partner, stage | An affiliate-labelled link opens |
| `deal_logged` | barter or paid | A deal is marked agreed |
| `ai_draft` | type | Phase 3 |
| `ai_draft_flagged` | type | Phase 3 |
| `trip_exported` | — | Export done |
| `trip_closed` | net balance band (for example "loss", "break-even", "profit"), not the exact figure | Stage 3 closes |
| `pitch_totals_opt_in` | on or off | Phase 2 tick changed |
| `nav_trip_click` | where (desktop nav, drawer, footer) | On the main website (1.20) |

## Rules

- No names, emails, places typed by the traveller, amounts or free text in any event.
- Respect the browser's Do Not Track / Global Privacy Control if the chosen tool supports it.
- The event list lives in the trip repo as one typed module, so a typo can't create a new event.

## Acceptance criteria

- [ ] Every event above fires once at the right moment, checked in the tool's debug view.
- [ ] A review of the payloads finds no personal data.
- [ ] A funnel from `nav_trip_click` to `trip_started` to `stage_completed: 3` can be built.
