## Why it matters

These stays are the first supply. The time it takes sets how fast new destinations can be added later, and the plan
says that pace is never faster than checking allows.

## What to do

For each stay, run the 7-step stay check from admin §4 and record the results in the sheet, in the same fields the
Strapi `stay` collection will use (task 1.09):

1. Map position, looked up once (Nominatim allows 1 request a second; never in bulk).
2. Recent guest photos compared with the listing.
3. Recent reviews from women travelling alone, summarised as a safety note.
4. WiFi, power backup, locker, laundry and free cancellation, confirmed with the stay.
5. Booking link, labelled.
6. Pehchan-checked: yes only if all of the above pass.
7. Open to creator stays: yes only if the stay agrees in writing. Save that message.

Cover the stay mix: base homestays or guesthouses, 1–2 hostels, one hero stay, and a chain hotel that can be paid
with points.

## Acceptance criteria

- [ ] 10–20 stays recorded with every field filled or marked "not known".
- [ ] Written OKs saved for every "open to creator stays" yes.
- [ ] Total hours spent recorded, and hours per stay worked out.
