## Why it matters

Nine steps (and E3 later) share one engine. Built once, admin can change text, links and rule numbers, and a new
step like E3 appears without new code.

## Parts

| Part | What it does |
|---|---|
| `StepCard` | Five sections: **How to do it** (guide text) · **Do it here** (links with "checked on" dates and affiliate labels) · **Your output** · **Counts as done when** · **Feeds**. A status chip and a "Skip" button that asks for a reason |
| `OutputForm` | Built from each step's field list: text, number with currency, date, link (https check), repeatable rows, tick |
| `EvidenceUpload` | Screenshots and files, stored in IndexedDB only |
| `LinkList` | Labels affiliate and network links, shows `checkedOn`, opens partner sites in a new tab, fires `affiliate_click` |
| `stepRules.ts` | One plain function per step that returns done or not, with what's missing. No browser code inside, so phase 3 can run it on the server |
| Autosave hook | Saves on every change (1.17) |

## Statuses

Not started → In progress (first field filled) → Done (rule passes). Done → In progress if an edit makes the rule
fail. Not started or In progress → Skipped (reason required; reason type sent with `step_skipped`). Skipped → In
progress when resumed. **Not needed** is set automatically (P3 on an India-only trip).

**Required in Creator mode:** E2, P1, P2, P3 (international only), S1. **Optional:** E1, P4, S2, S3. Read from
`step-guide`, not hard-coded.

Cards are grouped under Earn, Points and Stay free and hidden in Just plan it safely.

## Partner sites

Every partner site is an outbound link. The page calls no partner API in stage 1, so approvals and links are what
the traveller reports.
