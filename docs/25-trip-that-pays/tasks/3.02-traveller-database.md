## Why it matters

From phase 3 trips are saved to accounts. Strapi runs on one EC2 server with SQLite and holds admin content, so
traveller data needs its own database with backups and room to grow.

## Requirements

| Need | Detail |
|---|---|
| Separate from Strapi | No traveller data in Strapi, ever |
| Hosted in or near India | Faster for travellers; check the DPDP Act position with the lawyer |
| Backups | Daily, with a tested restore |
| Files | Screenshots and evidence uploads need file storage |
| Cost | Free tier first if one fits; anything paid goes to the owner first |
| Migration | IndexedDB trips upload when the traveller signs in, using the same versioned format as export (1.17) |

## Output

A one-page decision note: options compared, choice, cost, backup plan. The owner signs it off.

## Acceptance criteria

- [ ] Decision note signed off.
- [ ] Database `DATABASE_URL` in environment variables only.
- [ ] Restore tested once.
