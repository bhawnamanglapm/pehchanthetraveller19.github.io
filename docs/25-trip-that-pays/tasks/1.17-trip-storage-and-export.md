## Why it matters

There's no login in phases 1–2, so the browser is the only copy of the traveller's trip. Losing it loses their money
diary, terms of deals and evidence. Export is the safety net.

## Storage

- **IndexedDB**, one record per trip, holding text and evidence files (screenshots, written terms, consent forms).
- The trip app's subdomain has its own storage, separate from the main website's. Nothing is shared between them.
- Every output records when it was entered.
- A version number on the stored shape, with a migration step, so a later release can't break saved trips.
- Several trips can exist (after "Next place"); one is open at a time.

## Autosave

Every change saves at once; there's no save button. A small "Saved" indicator confirms it. If saving fails (storage
full, private browsing), the page says so plainly and offers export.

## Trip menu actions

| Action | Behaviour |
|---|---|
| **Export my trip** | One file (JSON plus the evidence files, zipped) and a PDF of the readable trip. The PDF is made in the browser; nothing is uploaded |
| **Import** | Reads that file back, checks the version, and asks before replacing a trip with the same ID |
| **Delete my trip** | Confirm step, then removes the trip and its files from the browser |
| **Clear-data warning** | Before the browser's own data is cleared the page can't intercept, so: on first save, ask the browser for persistent storage; show a reminder to export when the trip has unsaved-to-file changes older than 7 days; explain on the "What we store" screen that clearing site data deletes the trip |

## Never stored (no fields exist for them)

Card numbers · full membership numbers (P1 takes the last 4 digits only) · passport details · programme passwords.

## Acceptance criteria

- [ ] Closing and reopening the browser keeps the trip, including screenshots.
- [ ] Export then import on another browser gives the same trip.
- [ ] Delete removes everything for that trip.
- [ ] No input anywhere accepts a full card or membership number (tested with a 16-digit number).
