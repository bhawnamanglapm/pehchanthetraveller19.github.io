## Why it matters

A destination appears only when every item is published, sourced and dated. The launch has one destination, so this
pack is the whole of the page's content at launch. How long it takes sets the pace for every later destination.

| # | Item | Source |

## The stay check (per stay)

Each stay must meet the 6-point check travellers see in 0b (safe, close to your shots, real, practical, flexible,
earns). Admin verifies it with these steps:

1. Map position looked up once and saved (Nominatim: 1 request a second, never in bulk). Note the walking distance
   to the sunrise and sunset spots.
2. Recent guest photos compared with the listing.
3. Recent reviews from women travelling alone read; safety note written.
4. WiFi, power backup, locker, laundry and free cancellation confirmed with the stay.
5. Booking link added and labelled.
6. **Pehchan-checked** set only if all of the above pass.
7. **Open to creator stays** set only after the stay agrees in writing, with the message uploaded.
