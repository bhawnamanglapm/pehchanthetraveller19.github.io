## Why it matters

Barter platforms check how old an account is and how many followers it has. TripGyani was found (earlier research,
not reconfirmed on 14 Nov) to ask for a one-year-old account and 5k+ followers. Barter's own pages say 2,000 or
2,500. Every month the account exists counts, so it starts before anything is built.

## What to do

1. If the account doesn't exist, create it as a **professional (creator or business) account**. Instagram's API
   needs a professional account, and phase 3 connects to it (task 3.07).
2. Profile: name, the one-line description from 0.01 (D1), and a link to the main website. Swap the link to the trip
   app once it's live (1.40).
3. Post the phase 0 trip as it happens (0.06): the choice of place, the stays, the real costs.
4. Label every partner post as ASCI requires (README §12), using Instagram's "Paid partnership" tool as well.
5. Record the follower count and the date on the 1st of each month, with a screenshot. This is the evidence the media
   kit uses later.

## Acceptance criteria

- [ ] A professional account exists, with the date it was created recorded.
- [ ] Monthly follower counts with screenshots are kept in one place the owner can find.
- [ ] No partner post goes out without an ad label.
