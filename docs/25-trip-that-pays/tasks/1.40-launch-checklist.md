## Why it matters

The trip app goes public and gets a link from every page of the main website. This is the gate that makes sure
nothing unchecked goes out.

## Before launch

**Legal and trust**
- [ ] Lawyer-approved consent screen, consent form (English and Hindi), privacy, terms (1.34).
- [ ] CA date: not needed for launch (moved to the people steps on 16 Nov 2026). Check `caApprovedOn` is empty, so
  the tax line stays hidden (1.34).
- [ ] Affiliate disclosure page live; every affiliate link labelled (1.35).

**Content**
- [ ] The AI-picked place accepted by the owner (1.41).
- [ ] The destination pack published, sourced and dated, with no amber warnings (1.36). No checked stays yet: 0b
  shows its "no checked stays yet" message (4.06 adds them).
- [ ] Step guides and links seeded; E3 and TripGyani hidden (1.10).
- [ ] Templates and trip-page-settings filled; AI off for every stage (1.11).
- [ ] Worked example: not needed for launch (moved to 4.03 on 16 Nov 2026). Check `workedExampleLink` is empty, so no
  example link shows and `/trip/example/` is out of the sitemap.

**Tech**
- [ ] Subdomain on HTTPS; robots and sitemap correct; preview is `noindex` (1.02).
- [ ] Strapi backup runs daily and a restore was tested (1.06).
- [ ] Revalidate webhook works from a real publish (1.13).
- [ ] Link-check, advisory and rate jobs ran once successfully; Vercel plan limits on cron checked (1.15).
- [ ] Public forms rate-limited; no IP stored (1.16).
- [ ] Export, import and delete tested; offline save tested (1.17, 1.18).
- [ ] Analytics events arrive with no personal data (1.19).
- [ ] Accessibility and slow-network checks signed off (1.33).
- [ ] No secrets in the repo; all keys in Vercel environment variables.

**Operations**
- [ ] Admin runbook done and first monthly session scheduled (1.38).
- [ ] Measures dashboard ready (1.39).

## Launch day

1. Deploy the trip app to production.
2. Merge the main website's nav link change (1.20) and deploy GitHub Pages.
3. Click the nav link from desktop, drawer and footer; check `nav_trip_click` arrives.
4. Run one full trip from the landing page to stage 1 on a phone.
5. Post the launch on Instagram. (The worked example gets its own post when 4.03 goes live.)

## Week after

- [ ] Check errors, drop-off and broken links daily for 7 days.
- [ ] Note what to fix first, before starting phase 2.
