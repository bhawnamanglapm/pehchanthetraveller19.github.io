# Content intake

**You write plain English here. I turn it into the site.**

You never have to touch JSON, HTML or CSS. Fill in a template in this folder,
tell me it's ready, and I convert it into `src/content/`, rebuild and deploy.

| File | Use it for |
|---|---|
| `DESTINATION.md` | A place you want a full guide for |
| `STAY.md` | A hotel, homestay, camp or lodge you have actually stayed in |
| `EXPERIENCE.md` | Something you did that is worth someone else's time |
| `STORY.md` | A piece of writing in your own voice |

## How to use it

1. Copy the template — e.g. `cp DESTINATION.md 01-manali.md`
2. Fill in what you know. **Leave anything blank that you don't know.**
   Blank is fine. Invented is not.
3. Tell me the filename and I'll build it.

Anything you leave blank, I either ask you about or leave off the page. I do not
fill gaps with plausible-sounding travel writing — that is exactly how the site
ended up generic the first time.

## The one rule

Write only what you actually know. If you've been there, say what you saw. If
you researched it, say so and I'll mark it as researched rather than first-hand.
A short guide about a place you know beats a long one about a place you don't.
